Password Checker 🔒

A simple password checker tool built with **HTML**, **CSS**, and **JavaScript**. This tool helps users evaluate the strength of their passwords based on various criteria, ensuring they create stronger passwords for better security. 🛡️

Features ✨

- Real-time Password Strength Evaluation: As the user types, the password's strength is evaluated and categorized as Weak, Moderate, or Strong.
- Criteria for Strong Password: 🔑
  - Minimum length of 8 characters.
  - Includes both uppercase and lowercase letters.
  - Contains at least one number.
  - Includes special characters (e.g., `!`, `@`, `#`, `$`, etc.).
- Visual Feedback: 🟢🟡🔴 The password strength is displayed with color-coded feedback:
  - Red for weak.
  - Yellow for moderate.
  - Green for strong.
- User-Friendly Interface: 💻 Simple and clean design to make password evaluation easy.

Technologies Used ⚙️

- HTML: For the structure of the web page.
- CSS: For styling and layout.
- JavaScript: For the logic behind evaluating password strength in real-time.
